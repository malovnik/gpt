# Telegram Group Monitor - Инструкция по настройке

Это программа для мониторинга Telegram-группы с автоматической генерацией умных сводок через OpenAI каждые 4 часа.

## Что программа делает

1. **Собирает сообщения** из указанной группы Telegram
2. **Анализирует через OpenAI** все сообщения за период (по умолчанию 4 часа)
3. **Выделяет важное:**
   - Вопросы, на которые можно ответить
   - Запросы о помощи
   - Предложения и полезности
   - Важную информацию и анонсы
4. **Проверяет ссылки** на доступность
5. **Отправляет сводку** в личные сообщения

## Настройка

### 1. Получите необходимые ключи

#### Telegram Bot Token
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Сохраните полученный токен (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
4. Добавьте бота в вашу группу и сделайте его администратором

#### ID группы для мониторинга
1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в вашу группу
2. Он отправит ID группы (например: `-1001234567890`)
3. Удалите бота из группы (он больше не нужен)

#### Ваш User ID
1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Он отправит ваш ID (например: `123456789`)

#### OpenAI API Key
1. Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com/)
2. Перейдите в [API Keys](https://platform.openai.com/api-keys)
3. Создайте новый ключ
4. Сохраните ключ (начинается с `sk-`)

### 2. Создайте конфигурационный файл

Создайте файл `config/local.json` со следующим содержимым:

```json
{
  "bot": {
    "token": "ВАШ_TELEGRAM_BOT_TOKEN"
  },
  "monitor": {
    "groupId": -1001234567890,
    "targetUserId": 123456789,
    "summaryIntervalHours": 4,
    "checkLinksEnabled": true
  },
  "openai": {
    "apiKey": "ВАШ_OPENAI_API_KEY",
    "model": "gpt-4-turbo-preview",
    "maxTokens": 4000,
    "temperature": 0.7
  }
}
```

**Замените:**
- `ВАШ_TELEGRAM_BOT_TOKEN` - токен вашего бота
- `-1001234567890` - ID группы для мониторинга
- `123456789` - ваш User ID
- `ВАШ_OPENAI_API_KEY` - ваш ключ OpenAI

**Опции модели OpenAI:**
- `gpt-4-turbo-preview` - лучшее качество, дороже (~$0.01/1K токенов)
- `gpt-3.5-turbo` - быстрее и дешевле (~$0.0015/1K токенов)

### 3. Установите зависимости

```bash
pnpm install
```

### 4. Соберите проект

```bash
pnpm build
```

### 5. Запустите бота

```bash
pnpm start
```

## Дополнительные настройки

### Изменить интервал сводок

В `config/local.json`:
```json
"summaryIntervalHours": 2  // для сводок каждые 2 часа
```

### Отключить проверку ссылок

```json
"checkLinksEnabled": false
```

### Использовать более дешевую модель

```json
"model": "gpt-3.5-turbo"
```

## Отладка

Для включения подробных логов установите:
```json
"debug": 2
```

Уровни debug:
- `0` - только ошибки
- `1` - основная информация (по умолчанию)
- `2` - подробные логи

## Требования

- Node.js 18+
- pnpm (или npm/yarn)
- OpenAI API ключ с доступным балансом
- Telegram бот с правами администратора в группе

## Возможные проблемы

### Бот не получает сообщения из группы
- Убедитесь, что бот добавлен в группу
- Убедитесь, что бот является администратором
- Проверьте правильность groupId (должен быть отрицательным для supergroups)

### OpenAI API ошибки
- Проверьте баланс на аккаунте OpenAI
- Убедитесь, что API ключ действителен
- Проверьте лимиты запросов

### Сводки не приходят
- Проверьте targetUserId - это должен быть ваш личный ID
- Убедитесь, что вы начали диалог с ботом (напишите `/start`)
- Проверьте логи на ошибки

## Поддержка

Если возникли проблемы, проверьте:
1. Логи в консоли
2. Правильность всех ID и токенов
3. Наличие прав у бота в группе
