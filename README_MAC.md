# 🚀 Telegram Group Monitor - Инструкция для Mac

Автоматический мониторинг Telegram группы с AI-анализом через OpenAI.

## 📦 Быстрый старт

### Шаг 1: Установка
Дважды кликните на файл:
```
setup.command
```

Это установит все зависимости и скомпилирует проект.

### Шаг 2: Конфигурация
Файл `config/local.json` уже создан с вашими данными:
- API ID: 18713108
- Phone: +79623959707

**Нужно добавить только OpenAI ключ!**

Откройте `config/local.json` и замените:
```json
"apiKey": "YOUR_OPENAI_KEY_HERE"
```

на ваш реальный ключ от OpenAI (получить на https://platform.openai.com/api-keys)

### Шаг 3: Найти ID группы
Дважды кликните на файл:
```
find-groups.command
```

Это покажет список всех ваших групп. При первом запуске:
1. Вам придет SMS код от Telegram - введите его
2. Если есть 2FA пароль - введите его
3. Программа покажет все ваши группы с их ID

Скопируйте ID нужной группы и добавьте в `config/local.json`:
```json
"groupId": -1001234567890
```

### Шаг 4: Запуск
Дважды кликните на файл:
```
start.command
```

Программа запустится и начнет мониторинг!

## 🎯 Что делает программа

1. **Собирает сообщения** из указанной группы в реальном времени
2. **Каждые 4 часа:**
   - Анализирует все сообщения через OpenAI
   - Выделяет важные вопросы, запросы, предложения
   - Проверяет все ссылки на доступность
   - Формирует красивую сводку
   - Отправляет сводку вам в личку Telegram

## ⚙️ Настройки (config/local.json)

```json
{
  "debug": 1,                    // 0 = минимум логов, 1 = норма, 2 = подробно
  "telegram": {
    "apiId": 18713108,          // Ваш API ID
    "apiHash": "...",           // Ваш API Hash
    "phoneNumber": "+7...",     // Ваш телефон
    "sessionName": "telegram_monitor"  // Имя файла сессии
  },
  "monitor": {
    "groupId": 0,               // ID группы для мониторинга (ОБЯЗАТЕЛЬНО!)
    "targetUserId": "me",       // Кому отправлять сводки ("me" = себе)
    "summaryIntervalHours": 4,  // Интервал сводок (часы)
    "checkLinksEnabled": true   // Проверять ссылки?
  },
  "openai": {
    "apiKey": "sk-...",         // Ваш OpenAI ключ (ОБЯЗАТЕЛЬНО!)
    "model": "gpt-4-turbo-preview",  // или "gpt-3.5-turbo" (дешевле)
    "maxTokens": 4000,
    "temperature": 0.7
  }
}
```

## 🔧 Требования

- **macOS** (10.14 или новее)
- **Node.js** 18.x или новее (скачать с https://nodejs.org/)
- **OpenAI API ключ** (получить на https://platform.openai.com/)
- **Telegram аккаунт** с доступом к нужной группе

## ❓ Частые вопросы

### Программа не может подключиться к Telegram?
Включите VPN - возможно Telegram заблокирован в вашей сети.

### Где взять OpenAI ключ?
1. Зайдите на https://platform.openai.com/
2. Зарегистрируйтесь или войдите
3. Перейдите в API Keys
4. Создайте новый ключ (начинается с `sk-`)

### Как узнать ID группы?
Запустите `find-groups.command` - он покажет все ваши группы с ID.

### Сколько стоит работа?
- OpenAI API: ~$0.01-0.03 за анализ (зависит от количества сообщений)
- При 4-часовых сводках и группе на 1000+ человек: ~$2-5/месяц

### Можно изменить интервал сводок?
Да! В `config/local.json` измените `summaryIntervalHours` (например, на 2 или 8).

### Программа видит закрытые группы?
Да! Она работает через ваш личный аккаунт, поэтому видит все группы, к которым у вас есть доступ.

## 🛑 Остановка программы

Нажмите `Ctrl+C` в окне терминала или просто закройте окно.

## 🔒 Безопасность

- Все ваши ключи хранятся локально в `config/local.json`
- Файл `local.json` добавлен в `.gitignore` и не попадет в git
- Сессия Telegram сохраняется локально (файл `telegram_monitor.session`)
- Никакие данные не отправляются никуда кроме Telegram и OpenAI API

## 📞 Поддержка

Если что-то не работает, проверьте:
1. Node.js установлен (`node --version` в терминале)
2. `config/local.json` заполнен корректно
3. OpenAI ключ действителен и есть баланс
4. VPN включен (если Telegram заблокирован)
5. ID группы указан правильно (с минусом!)
